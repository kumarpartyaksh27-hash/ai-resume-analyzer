# 📄 AI Resume Analyzer & ATS Matcher

An intelligent ATS Resume Analyzer built with Streamlit and Google Gemini API that evaluates resumes against target job descriptions, providing detailed match scores, strengths, skill gaps, and improvement suggestions.

## 🚀 Features
- 📄 PDF Parsing (using `pypdf`)
- 🎯 Job Description Compatibility Matching
- 📊 Match Score (%) & Detailed ATS Feedback
- 💡 Recommendations for Improvement

## 🛠️ Tech Stack
- Python
- Streamlit
- PyPDF
- Google Gemini API (`gemini-2.5-flash`)
